# Affiche « Reste Premium »

Affiche 4:5 (exportée en 2160×2700) inspirée d'une affiche de référence, adaptée à Digital Pass.

- `fond.png` : visuel généré avec GPT Image 2 (ElevenLabs), sans texte ni marque
  (une première version qui citait les marques a été refusée par le générateur).
- `affiche.html` : textes, boutons, logo et badges posés par-dessus (orthographe garantie).
- Export : `node render.cjs` → `affiche-digital-pass.png`.
